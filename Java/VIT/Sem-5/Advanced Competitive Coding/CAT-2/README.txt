JAVA LAB ASSESSMENT PACK

Each source is an independent program with class Main. Copy the selected source to Main.java if your lab IDE requires that filename.

Input:
01 Booth: m q
02 Euclid: a b
03 Karatsuba: x y
04 Longest ones after flipping bit: one integer
05 Swap nibbles: one byte value
06 Block swap: n d, followed by n array elements
07 Max product subarray: n, followed by n elements
08 Maximum hourglass sum: 36 integers for a 6x6 matrix
09 Max equilibrium sum: n, followed by n elements
10 Leaders: n, followed by n elements
11 Majority element: n, followed by n elements
12 Lexicographically first palindromic string: one string

EXPLANATIONS.txt contains a 20-word gist and concise algorithm for each.
